# sonukp.in — Under Construction

Simple static landing page for GitHub Pages.

## Files

- `index.html` — webpage
- `style.css` — styling

## GitHub Pages

Upload both files to the root of your `sonukp.github.io` repository and configure GitHub Pages to deploy from the `main` branch and `/ (root)`.

Then configure the custom domain as `sonukp.in` under:

Repository → Settings → Pages → Custom domain

## Before going live

Replace the `#` placeholders in `index.html` with your actual LinkedIn, Google Scholar and ORCID URLs.
